# Series plan

**Series:** 我每天都在跑 Spark，卻不完全知道它怎麼跑：一名 MLE 的 30 次資料系統探索

| Episodes | Arc | Runtime |
| --- | --- | --- |
| Ep01–04 | Start from a familiar local job | PySpark local mode + Spark UI |
| Ep05–11 | Follow the execution engine | local mode + event logs |
| Ep12–17 | Explain performance behavior | local mode + controlled data |
| Ep18–21 | Leave local mode | Docker Spark standalone cluster |
| Ep22–26 | Follow a submitted job | Docker YARN/HDFS learning cluster |
| Ep27–30 | Return to real MLE workflows | integration; Kubernetes optional |

Every episode should be designed for 30–60 minutes after the initial setup:
10–15 minutes to establish a question, 15–25 to run the smallest experiment,
and 15–20 to record evidence and draft the post.
